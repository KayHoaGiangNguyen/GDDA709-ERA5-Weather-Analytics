# Data Visualizations

This directory contains visualizations generated during the ERA5 atmospheric data analysis for Auckland, New Zealand.

## Contents

The visualizations cover:

- Annual average temperature trends.
- Monthly temperature patterns.
- Average temperature across different pressure levels.
- Geopotential height and atmospheric pressure analysis.
- Relative humidity patterns.

## Purpose

These visualizations support the exploration of temporal and atmospheric patterns in the ERA5 dataset and help communicate the findings from the MapReduce analysis.
